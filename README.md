# Projeto de inglês — carrossel

## Estrutura

```text
projeto-ingles-andre-carousel/
├── index.html
├── anime/
│   ├── anime1.png
│   ├── anime2.png
│   ├── anime3.png
│   └── ...
└── assets/
    ├── dna.svg
    └── abstract-art.svg
```

## Como colocar suas imagens de anime

1. Abra a pasta `anime`.
2. Coloque suas imagens nela.
3. Renomeie em sequência:
   - `anime1.png`
   - `anime2.png`
   - `anime3.png`
   - `anime4.png`
4. O site procura automaticamente até `anime20.png`.
5. Não precisa alterar o código para adicionar ou remover imagens.

## Importante

- Os nomes devem estar em letras minúsculas.
- O formato esperado é `.png`.
- Não pule números no começo da sequência para facilitar a organização.
- Abra `index.html` no navegador.
